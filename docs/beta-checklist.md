# Beta checklist

- [ ] Backend `/health` and `/api-docs` respond over HTTPS.
- [ ] Search and Gemini keys are configured outside source control.
- [ ] Redis is reachable and cache hits appear in backend logs.
- [ ] Load the unpacked extension and reload it after each build.
- [ ] Test a short post, long post, thread, quote, reply, and selected text.
- [ ] Test both context-menu actions and open at least one source card.
- [ ] Confirm timeout, missing-provider, and invalid-request errors are readable.
- [ ] Record latency, cache hit rate, failed analyses, and user feedback.
